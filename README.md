# Guess the Number

A simple command-line number guessing game developed using Python.

## Features

* Randomly generates a number for the player to guess
* Two difficulty levels: Easy and Hard
* Easy level provides **10 attempts**
* Hard level provides **5 attempts**
* Gives hints when the guess is too high or too low
* Displays the result after the attempts are completed

## Technologies Used

* Python

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python main.py
```

## How to Play

1. Start the game.
2. Choose a difficulty level:

   * **Easy** → 10 attempts
   * **Hard** → 5 attempts
3. Enter your guess.
4. The game will tell you whether your guess is too high or too low.
5. Continue guessing until you find the correct number or run out of attempts.

## Project Purpose

This project was created to practice Python programming, user input, conditional statements, loops, random number generation, and basic game logic.
